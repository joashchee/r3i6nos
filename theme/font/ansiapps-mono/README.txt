ANSIapps Mono in r3i6nos (theme/font/ansiapps-mono/)
=====================================================

ANSIapps Mono is the one official font of the ansiapps family and of every r3i6nos app. This folder holds its 10 x 20 size as the theme reads it. Every file
here is GENERATED by scripts/build_ansiapps_font.py from the font's own repository (ansiapps-mono-font): do not edit; change the font there and run the script.

The font is clean-room: every glyph was drawn from a written brief and the Unicode character names, with no other font's shapes or outlines as a source (the
repository's provenance log says who drew each batch). It replaced R3i6nos Mono (2026-11-25), whose code page 437 letters were VileR's CC BY-SA 4.0 font.

Licence: SIL Open Font License 1.1, Reserved Font Name "ANSIapps Mono" (OFL.txt). The tables here are the font in other formats; they carry the same licence.
The generating script is MIT, as the rest of r3i6nos.

Files: ansiapps_mono10x20.h (C), ansiapps_mono10x20.lua (LOVE), ansiapps-mono.json (web canvases and the screen mirror), AnsiappsMono10x20-Regular.bdf,
ansiapps_mono_names.h|.lua and glyph-names.json (every named glyph and its size), ansiapps_cp437.h|.lua (code page 437 on the font), ansiapps_portrait.h|.lua
(the portrait maker's parts and join tables), glyph-coverage-report.txt.
Identifiers keep the r3mono_ prefix (r3mono_find, r3mono_name, R3I_*): the names the apps already call.
